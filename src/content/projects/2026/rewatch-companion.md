## Overview

Rewatch Companion is a static essay site for people revisiting shows they already know, with episode-by-episode guides and broader character and theme analysis that can freely discuss the full series. An offline Python pipeline uses LLM agents to research, draft, and revise each essay, then publishes the reviewed results as static MDX through an Astro frontend. It currently includes complete companions for _Succession_ and _Breaking Bad_.
